01 / what I can help with

Technical work with a clear problem to solve.

I am most useful when something needs to be built, connected, repaired, secured, or made to work outside localhost.

  1. 01Backends and APIs that do the required jobDesigning endpoints, data flows, authentication, and the server-side logic behind a small product or feature.
  2. 02Frontends that actually reach the backendConnecting forms, sessions, APIs, errors, and state when the two halves currently disagree.
  3. 03Existing projects brought back to lifeTracing bugs, finishing partially working builds, and making sense of code generated with AI but never fully integrated.
  4. 04Deployments that work beyond one laptopFinding environment, configuration, domain, HTTPS, database, and production-only failures.
  5. 05Small tools that remove repetitive workScripts, command-line utilities, data helpers, and focused automation built around a real workflow.
  6. 06Security-minded custom developmentAuthentication, input handling, secret storage, access control, and small technical projects where trust boundaries matter.

Small requests are still requests

Not every useful fix needs to become a formal freelance project. Send the tiny problem too; if it is genuinely quick, I may just help without turning it into an invoice.
